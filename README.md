# ☁️ Cloud Notes

Welcome to **Cloud Notes**!

- Build hands-on skills through labs and projects
- Track my progress with Git and GitHub

The roadmap covers:

- Computer Fundamentals

- Networking
- Python

- Kubernetes
- Terraform

Each week includes notes, labs, reflections, and practical exercises.
