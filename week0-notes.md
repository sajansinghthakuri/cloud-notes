## Lab Environment

I installed **VirtualBox** and created my first virtual machine using **Ubuntu Server 24.04 LTS**.

### VM Configuration

- **Operating System:** Ubuntu Server 24.04 LTS
- **CPU:** 2 vCPUs
- **Memory:** 4.49 GB RAM
- **Storage:** 30 GB Virtual Disk
- **Network:** Bridged Adapter

After the installation, I created a snapshot named **clean-install**. This will allow me to restore the VM to a clean state whenever I make mistakes while practicing.
